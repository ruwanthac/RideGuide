# Assets

Add your app images here for local use:

- `logo.png` - App logo (recommended: 200x200px)
- `login-hero.png` - Login screen hero image (recommended: 800x400px)

The login screen uses remote images by default. Replace the LOGO_IMAGE and HERO_IMAGE URLs in LoginScreen.tsx with:
  require('../../assets/images/logo.png')
  require('../../assets/images/login-hero.png')
